# Issue tracker

Use `lit` to coordinate projects, issues, and work claims with a tracker selected
for the current task. Follow the installed `lit` skill and executable help for
connection and command syntax. Do not infer a live endpoint, project, or session
from this source checkout.

See [installation](../installation.md) for service setup and client connections,
[CLI help](../cli-help.md) for command usage, and
[verification](../development/testing.md) for isolated development checks.

Keep local planning notes, agent transcripts, and private tracker state outside
version control. `.scratch/` is ignored for local working notes.
